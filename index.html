Selected work

1

FRAMED benchmark: reproducing a published bicycle-frame surrogate study, then extending it with physics

Published report PyTorch, scikit-learn, XGBoost, AutoGluon

Problem
A peer-reviewed study (MIT DeCoDE Lab, Computer-Aided Design, 2023) released 4,047 FE-simulated tubular frames and a surrogate benchmark. Do its claims hold on the released data, and does structural physics improve the models?
Method
Re-derived the paper’s dataset claims from the released file. Rebuilt its five regressors with the authors’ hyperparameters on 10 × 5-fold cross-validation. Added beam-theory features (area, EI, GJ, slenderness, analytic mass), log-scaled targets, guardrails and 95% intervals, scored on identical folds.
Result
  • 11 of 11 checkable dataset claims reproduce; the published model ranking holds.
  • R² 0.747 and −13% MAE for the best physics model against the best reproduced paper model. The R² gain is not significant over 5 folds (p = 0.15).
  • −23.8% mass and −30.5% in-plane deflection for re-sized titanium frame 3853 at mean SF ≥ 1. Surrogate-predicted, not FE re-verified.

Read the benchmark report View the code on GitHub

In development SciPy FFT, PyTorch 1D-CNN, Plotly

Problem

Method
Convert road-load data into power spectral densities and use a 1D-CNN to predict resonance risk and random-vibration fatigue damage.

3D FEA mesh-to-stress graph neural network surrogate

Upcoming PyTorch Geometric GATv2, pyNastran

Problem
Predict nodal stress fields directly from geometry, generalizing across mesh topologies without re-solving.
Method
Read Nastran meshes with pyNastran, treat grid points as nodes and element connectivity as edges, and train an attention-based GNN (GATv2).

Research is upcoming; no results claimed yet.
