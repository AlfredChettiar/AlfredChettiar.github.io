# Portfolio Website Rules
- Pure semantic HTML5, modern responsive CSS3, and vanilla JavaScript (no Node/React build step required so GitHub Pages deploys directly from `main`).
- Maintain a crisp, technical engineering aesthetic: a light "materials test datasheet" (white sheet, graphite ink, ruled structure, condensed Archivo for headings and figures, generous whitespace). Colour only where it carries meaning: cyan for this study's data and links, amber for in-progress status, grey for published reference values.
- Ensure mobile responsiveness and fast load speed.
